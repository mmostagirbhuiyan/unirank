# Match Universities Script Guide 🧩

**Detailed guide for the legacy fuzzy matching script (`scripts/match-universities.js`)**

---

## 📋 Overview

The `scripts/match-universities.js` script is a **legacy tool** primarily used for generating bulk, auto-suggested university name mappings based on fuzzy string matching. While still functional, its role has largely been superseded by the more robust and efficient pattern-based matching implemented in `scripts/enhanced_name_matcher.js`.

This script was historically used to generate `frontend/public/data/suggested-university-mapping.json`, a large file containing ~39,000 fuzzy matches. It operates by comparing university names across different sources and suggesting a standardized name if a high similarity threshold is met.

**It is generally not recommended to run this script frequently.** The enhanced matching system handles most of the complex standardization automatically, reducing the need for bulk fuzzy matching regeneration.

---

## 🔧 How It Works

The `match-universities.js` script performs the following key steps:

1.  **Loads Data**: It loads all university data that has been processed and standardized by `scripts/scrape-rankings.js` (which includes data from all sources).
2.  **Identifies Canonical Names**: It identifies a set of canonical (standardized) university names, often from a reference source like US News.
3.  **Fuzzy Matching**: For each university name from other sources, it performs fuzzy string matching against the canonical names.
    -   It uses a `string-similarity` library to calculate a similarity score.
    -   If the similarity score exceeds a predefined threshold (typically 85%), a mapping suggestion is generated.
4.  **Generates Mappings**: It creates `suggested-university-mapping.json` containing entries like:
    ```json
    {
      "originalName": "University of Cambridge (QS)",
      "source": "qs",
      "suggestedStandardizedName": "University of Cambridge (Standardized)"
    }
    ```
5.  **Outputs Report**: It may also output a report on the number of new mappings generated and the effectiveness of the matching.

### Key Functions:

-   The script's main execution flow typically involves loading data, performing nested loops for comparisons, and writing results.

---

## 🚀 Usage

You should **only run this script when necessary**, for example:

-   When adding a **completely new university ranking source** with significantly different naming conventions that are not covered by existing pattern rules.
-   When the quality of the automated `suggested-university-mapping.json` degrades significantly.

To run the script:

```bash
node scripts/match-universities.js
```

### Parameters:

-   This script typically does not take command-line parameters, or if it does, they are internal configurations for similarity thresholds or input/output paths.

### Example:

-   **Regenerate all fuzzy matching suggestions**:
    ```bash
    node scripts/match-universities.js
    ```

---

## 📊 Key Outputs

-   **`frontend/public/data/suggested-university-mapping.json`**: This is the primary output file. It will be overwritten each time the script is run. This file serves as a fallback for the name standardization process if pattern-based matching or manual mappings do not yield a result.
-   **Console Logs**: Provides information on the progress of mapping generation.

---

## 🔍 Troubleshooting

-   **Long Execution Time**: Due to the nature of fuzzy matching a large number of names, this script can take a significant amount of time to run (e.g., several minutes).
-   **Incorrect Mappings**: If the generated `suggested-university-mapping.json` contains incorrect matches, you might need to:
    -   Adjust the similarity threshold within the script.
    -   Add more specific manual mappings to `manual-university-mapping.json` to override these auto-generated suggestions.
    -   Improve the pattern-based rules in `enhanced_name_matcher.js`.
-   **No New Mappings**: Ensure that the input data for the script is correct and that the similarity threshold is not set too high.

---

## 🔗 Related Components

-   `scripts/scrape-rankings.js`: Consumes the `suggested-university-mapping.json` as a fallback for name standardization.
-   `scripts/enhanced_name_matcher.js`: The primary name standardization engine that has largely replaced the need for this script.
-   `frontend/public/data/suggested-university-mapping.json`: The output file generated by this script.
-   `frontend/public/data/manual-university-mapping.json`: Manual overrides that take precedence over auto-generated mappings.

---

## 💡 Maintenance & Updates

-   **Infrequent Use**: Due to its legacy status and the improved `enhanced_name_matcher.js`, this script should be used and updated infrequently.
-   **Algorithm Enhancements**: If there's a need for more sophisticated fuzzy matching, updates to the `string-similarity` library or a different algorithm might be considered.
