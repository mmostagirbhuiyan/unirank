# Data integrity verification

Run `node scripts/scrape-rankings.js --offline` to regenerate from the checked-in source snapshots, then `node scripts/generate-frontend-insights.js`. The offline flag prevents an unrelated ranking-cycle refresh during identity repairs.

Run `npm test` and `node scripts/data-integrity-check.js`. The checker rebuilds identities and scores, compares both published files and the displayed total, and requires every input source record to have exactly one published owner. Unresolved records never count as conserved. University count is an output, not a target.

Matching uses country-scoped formatting equivalence, including word segmentation, before evaluating manual alias components. It preserves campus and institutional qualifiers, rejects components with multiple records from the same source, and does not use fuzzy suggestions to assign ranks. Historical names and translations require source-backed identity data, not similarity thresholds. QS and ARWU snapshots are decoded as Latin-1. THE is refreshed directly from its publisher’s public 2027 table and saved as UTF-8; the THE reader also supports the previous Latin-1 snapshot when offline or when a refresh fails.

The published `identity-audit.json` records each accepted source name, country and rank. Publication stops if same-source identity conflicts remain unresolved. This does not detect every cross-source split or certify semantic identity completeness. Incorrect source labels must be repaired against official source evidence rather than selecting the first, last or best rank. The [repair ledger](RR-UNIRANK-DATA-MATCH-source-repairs.json) preserves original labels, corrected labels, unchanged ranks, source locations and consultation dates. Researched aliases carry their evidence in `manual-university-mapping.json`.

See [the task report](RR-UNIRANK-DATA-MATCH-report.md) for verification and [the row changes](RR-UNIRANK-DATA-MATCH-changes.json) for every affected university. Similar names with disjoint sources are not sufficient evidence of institutional identity. Systems and separate campuses must remain separate.

Country-scoped phrase expansions are recorded in `identity-phrases.json`. They preserve campus words and remain subject to whole-component source-conflict checks. Source-specific geographic corrections are recorded in `identity-country-overrides.json`, with original labels retained as `sourceCountry`. Open semantic identity decisions are tracked in [the review ledger](RR-UNIRANK-DATA-MATCH-open-review.json). Passing tests and conservation checks alone are not release approval.
