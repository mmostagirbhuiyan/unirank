# Automation Helpers V2 Usage Guide

This guide describes how to use the existing automation helper scripts with the V2 pipeline. The helpers provide pattern discovery, safe pattern testing and baseline monitoring utilities.

## Running in V2 Mode
Each helper accepts a `--v2` flag that tells the script to operate on the V2 configuration files and staging directories.

Example: discover patterns using the canonical list generated by the V2 pipeline.
```bash
node scripts/automation-helpers/pattern-discovery.js --v2
```

Safely test a transformation pattern against V2 staging data:
```bash
node scripts/automation-helpers/pattern-tester.js "UC Campuses" "cleaned.replace(/^University of California - (.+)$/, 'University of California $1')" --v2
```

Monitor the health of the V2 staging directories:
```bash
node scripts/automation-helpers/baseline-monitor.js health --v2
```

## Notes
- When `--v2` is specified the helpers read from `canonical-universities.json` and the `staging/` directories rather than the legacy data locations.
- All existing flags continue to work. The `--v2` flag simply switches the default paths.

These tools assist with rule development and system monitoring as the new pipeline is rolled out.
